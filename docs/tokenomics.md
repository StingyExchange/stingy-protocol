# Tokenomics

**Status: not announced.** The $STINGY token has no published contract address, supply, allocation or vesting schedule. This page records the structure that will be used and the rules it must follow. It deliberately contains no numbers, because no numbers have been confirmed.

## Structure that will be published

When details are ready they will be released together, in one place, and mirrored on stingy.exchange. Each of the following sections will be filled in with a stated source.

### Supply

Total supply, decimals, and whether supply is fixed or can change.

### Distribution

How supply is divided between community, liquidity, development and any other group, with the reasoning for each share.

### Vesting and locks

Which allocations are locked, for how long, and how a holder can verify the lock on chain.

### Liquidity

Where the token will trade, who provides the liquidity, and whether it is locked.

### Utility

What holding the token does, if anything. Any utility that is not live will be labelled as planned.

### Fees

What Stingy charges, if anything, and where it goes. The current answer is that no fee schedule exists.

## Rules for publishing

1. Numbers appear only after they are final and verifiable on chain.
2. The contract address is published once, in the contract slot on the site and in the README together.
3. No allocation is described as locked unless the lock can be checked on chain.
4. Anything planned is labelled as planned, never as done.

## Verification

Once a contract address exists, anyone should be able to confirm supply, holders and transfers on a public block explorer. Do not trust an address that reaches you through chat, replies or direct messages. Compare it with the site and this repository.
